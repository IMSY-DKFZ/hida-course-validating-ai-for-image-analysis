# Validating AI for Image Analysis

This repository contains the hands-on exercises accompanying the [HIDA lecture series "Validating AI for Image Analysis"](https://events.hifis.net/event/3669/), taught by Annika Reinke (Helmholtz Imaging, DKFZ) and Evangelia Christodoulou (DKFZ).

The workshop introduces key concepts and practical techniques for validating AI methods in image analysis, including performance metrics, uncertainty quantification, and ranking robustness.

## Repository structure

The repository is organized by lecture day, for example:

```text
lecture1/
├── Practical1_classification.ipynb
├── Practical2_segmentation.ipynb
└── ...
```

The lecture includes all practical exercises from the lecture series.

## Requirements

The practical exercises are provided as Jupyter notebooks. Dependencies are specified within the individual notebooks where needed.
